# Study Compass

AI-powered study assistant built using Python and NVIDIA-hosted Llama models.

## Features

- Log Study Sessions
- AI Doubt Solver
- Personalized Study Recommendations

## Technologies Used

- Python
- OpenAI SDK
- NVIDIA API
- Llama 3.1

## Installation

pip install -r requirements.txt

## Setup

Create a .env file:

NVIDIA_API_KEY=your_key

## Run

python main.py
